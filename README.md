# ⚡ AgentFlow — Autonomous Multi-Agent Visual Workspace

AgentFlow is an interactive web-based canvas that allows developers to visually chain AI models, triggers, and execution nodes into automated multi-agent workflows in real time.


## 🚀 Key Features

- **Interactive Visual Canvas:** Drag, connect, and configure execution nodes effortlessly.
- **Real-Time Execution Engine:** Step-by-step topological execution with live glowing connection paths and status tracking.
- **Gemini API Integration:** Directly execute prompt nodes using `gemini-2.5-flash` or custom LLM endpoints.
- **Pre-Built Templates:** Instant workflow setup for common patterns like *GitHub PR Auto-Reviewer* and *AI News Synthesizer*.
- **Workflow Export:** One-click JSON workflow configuration exporter.

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Lucide Icons
- **AI Orchestration:** Google Gemini API
- **State Management:** React Context / Custom Hooks
